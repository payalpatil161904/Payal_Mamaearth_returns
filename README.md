# Mamaearth Returns & Growth Intelligence Pipeline

## Project Overview

This project analyzes e-commerce orders to understand revenue performance, customer returns, and operational risks using SQL, Python, and Generative AI.

## Project Objectives

- Analyze order revenue and customer purchasing patterns using SQL.
- Clean and validate transactional data using Python.
- Investigate payment-method return rates and high-risk customer segments.
- Analyze monthly revenue trends and quantity outliers.
- Generate a business narrative using the Situation, Complication, Resolution (SCR) framework.

## Technology Stack

- MySQL Workbench
- Python
- Pandas
- Matplotlib
- Google Gemini API

## Key Findings

- Raw revenue: ₹99,860.20
- Cleaned revenue: ₹97,358.30
- Revenue reconciliation difference: ₹2,501.90
- COD return rate: 44.4%
- Highest-risk segment: COD + Tier-2, with a 54.5% return rate
- Corrected revenue peak: March 2026, at ₹20,318.90

The analysis uses the dataset supplied for this capstone project. The findings describe that dataset and should not be interpreted as verified operational data from Mamaearth.
